# layer-esm v1.2.3 中文入门文章计划

## 目标与边界

- 计划文章：`guides/RELEASE_NOTES/introducing-layer-esm-v1.2.3.zh-CN.md`。本文档仅规划内容，不创建文章正文。
- 读者是首次使用 `layer-esm` 的开发者。先让读者学会 `msg` 和 `alert`，再介绍图标名称，最后通过简单示例认识其他常用方法。
- 每个示例只解决一个问题，使用包根路径导入所需方法。说明紧跟示例，避免长篇原理、迁移比较和高级配置。
- 保持自然的中文标题。不使用“具名图标”，不反复以“显示”开头，也不设置冗长的“风险与注意事项”章节。

## 拟定结构

文章标题为“layer-esm v1.2.3：消息提示、对话框与图标”。正式写作时按以下顺序组织：

1. 安装：给出 `npm install layer-esm`，说明后续示例从包中导入方法。
2. 快速开始：以“`msg`：消息提示”和“`alert`：提醒对话框”为小节，展示最基本用法。不要先介绍内部实现。
3. “Icon：消息图标”一节：列出 `warning`、`success`、`error`、`question`、`lock`、`sad` 和 `smile`，然后用一个 `msg` 示例展示 `icon: "success"`。沿用已讨论的 `Icon` 加中文用途的标题风格。
4. 更多常用方法：为 `confirm`、`load`、`tips`、`prompt`、`tab` 和 `open` 各设一个“方法名：用途”小节，每节只给一个容易理解的例子。`load` 示例同时使用 `close` 结束加载状态，不另造独立的 `close` 场景。

示例应各自包含必要的导入语句，不依赖前一个示例的变量。`tips` 示例明确目标元素；`prompt` 示例展示输入值的处理；`open` 示例保持内容简单，不把复杂选项当作入门前提。

## 写作前核对

- 以 [`src/index.ts`](../src/index.ts)、[`src/core/layer.ts`](../src/core/layer.ts) 和 [`src/core/types.ts`](../src/core/types.ts) 为 API、参数、回调和图标名称的事实来源；用 [`README.md`](../README.md) 核对安装命令与公开说明。
- 核实 `msg` 的自动关闭行为、`load` 的默认关闭行为，以及 `confirm`、`prompt` 的回调参数，避免让示例暗示错误行为。
- 区分 `load(0)` 等数字加载样式和字符串图标名称，避免把静态状态图标称作加载动画。
- 字符串弹层内容按可信 HTML 处理。示例仅使用固定文本；如果文章提到动态内容，用一句话提醒不要直接传入未经处理的用户 HTML。
- 参考现有的 [v1.0.1 中文文章](RELEASE_NOTES/introducing-layer-esm-v1.0.1.zh-CN.md) 了解发布位置和读者语境，但不沿用其中的迁移长篇结构或未经源码复核的技术表述。

## 完成标准

- 文章让新手按“安装 → `msg`/`alert` → Icon → 其他方法”的顺序阅读，每个方法都有一个可独立理解的示例。
- 图标名称、导入路径、参数和回调与当前代码一致；文章不把 React 内部实现作为使用前提。
- 标题自然、层级简洁，中文术语、空格和标点一致；不出现重复的“显示”式标题或不必要的风险章节。
- 正式写作获确认后，再创建文章并检查 Markdown 链接及相关文档索引。本计划阶段不修改文章、索引、源代码或生成文件。
